# Slack 利用

- [ユーザー向けプロフィール設定](user-settings.md)：Slack のアカウントを登録するとき、メンバーの識別やメンションをしやすくしたいとき

- [メンションと通知のタイミング](mentions-and-notifications.md)：広い範囲へ通知したくなったとき、業務時間外に投稿するとき、不在を知らせるとき
