# テクニカルライティング

- [出典と適用範囲](about.md)：これらの規約がどの文書に適用されるかを確かめるとき、出典やライセンスを確かめるとき
- [メッセージ設計](message-design.md)：報告や依頼、設計書を書き始める前に、伝えるメッセージを設計するとき
- [導入の作法](introduction.md)：文章やチャットの書き出しを書くとき、久しぶりのスレッド更新や定期報告を書くとき
- [本論の作法](main-body.md)：意思決定や承認を求めるとき、障害などで状況把握と支援を求めるとき
- [構造化](structuring.md)：複雑な情報を整理して伝えるとき、箇条書きや表の使い分けを決めるとき
- [簡潔さ](conciseness.md)：件名や主題文を書くとき、一文一義で文章を研ぎ澄ますとき
- [用語の正確性](terminology.md)：用語を選ぶとき、表記ゆれや解釈のブレを防ぎたいとき
- [具体例の使い方](examples.md)：抽象的な表現や境界値・異常系を説明するとき、例示が過剰か確かめるとき
- [実践パターン](patterns.md)：設計書や規約、提案資料を書くとき、図解の種類を選ぶとき
- [アンチパターン](anti-patterns.md)：ドキュメントのアンチパターンを避けたいとき、レビューするとき
- [セルフレビュー](self-review.md)：文章を書き終えてレビューを依頼する前に点検するとき
- [レビュー依頼](review-request.md)：完成前の文章のレビューを依頼するとき
- [フィードバック技術](feedback.md)：書き手を育成するとき、メッセージ文や見出しにフィードバックするとき
