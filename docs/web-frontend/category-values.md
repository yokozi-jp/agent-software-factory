# Webフロントエンドの区分値の管理方式

区分値 (参照データ) は何かしらの手法で取得・保持する必要がある。区分値取得 API の是非は Web API 設計ガイドラインに記載がある。
出典は [Webフロントエンド設計ガイドライン](about.md) (CC BY 4.0) で、OKF の形式に合わせて分割、変更している。

プルダウン項目などの生成のため、区分値（参照データとも呼ばれる）を何かしらの手法で取得・保持する必要がある。
