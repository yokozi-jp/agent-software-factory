# Webフロントエンドの画面間パラメータ連携

共有・再アクセスしたいデータはパスまたはクエリパラメータ、URL で見せてはいけないデータはオンメモリか Web ストレージを使う。
出典は [Webフロントエンド設計ガイドライン](about.md) (CC BY 4.0) で、OKF の形式に合わせて分割、変更している。

画面表示に必要なパラメータを保持し、受け渡す方法は下表の通り複数存在する。

| #                  | パスパラメータ                                                         | クエリパラメータ                                                       | オンメモリ                                                                   | Web ストレージ                                                               |
| :----------------- | :--------------------------------------------------------------------- | :--------------------------------------------------------------------- | :--------------------------------------------------------------------------- | :--------------------------------------------------------------------------- |
| 用途               | リソースの識別子                                                       | リソースを新規作成、参照、更新・削除、承認する際の前提となる条件       | アプリケーション内部で利用する一時的なデータ（主に画面間共通データ）         | アプリケーション内部で利用する長期的なデータ（主に画面間共通データ）         |
| 例                 | ID                                                                     | 検索条件                                                               | APIレスポンスなどのキャッシュ                                                | ユーザー設定など、比較的軽量で永続的な画面共通データ                         |
| URL表現            | URL に含まれる                                                         | URL に含まれる                                                         | URL に含まれない                                                             | URL に含まれない                                                             |
| リロード時         | ✅️維持される                                                           | ✅️維持される                                                           | ❌️維持されない                                                               | ✅️維持される                                                                 |
| ブラウザ履歴       | ✅️残る                                                                 | ✅️残る                                                                 | ❌️残らない                                                                   | ❌️残らない                                                                   |
| 得意なユースケース | ✅️簡単に共有や再アクセスをしたい ✅️URLにて見せてもよいデータを扱いたい | ✅️簡単に共有や再アクセスをしたい ✅️URLにて見せてもよいデータを扱いたい | ✅️複雑に構造化されたデータ扱いたい ✅️URLにて見せてはいけないデータを扱いたい | ✅️複雑に構造化されたデータ扱いたい ✅️URLにて見せてはいけないデータを扱いたい |

推奨は以下の通り。

- 直接リンクによる参照や共有を可能にしたい場合は、パスパラメータまたはクエリパラメータを利用する
- URL で見せてはならないデータを扱いたい場合、オンメモリ（アプリケーション実行中のみ保持）またはWebストレージ（ブラウザ終了後も保持したい場合）を利用する
- データの性質（一時的/永続的の別、共有範囲、セキュリティ要件）に応じて、オンメモリとWebストレージ（localStorage/sessionStorage）を使い分ける
