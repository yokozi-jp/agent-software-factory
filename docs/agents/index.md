# エージェント設定

- [Issue tracker](issue-tracker.md)：skill が Issue を作成、参照、更新するとき、wayfinder の調査チケットをサブエージェントに渡すとき
- [Triage ラベル](triage-labels.md)：Issue に triage ラベルを付けるとき
- [ドメイン文書](domain.md)：GLOSSARY.md と ADR の配置を確かめるとき、ドメインの用語や ADR を書くとき
- [タスクの区切りでの振り返り](retro.md)：commit、PR、Issue を閉じることのどれかをしたタスクで、完了を報告する前、振り返りの候補をどこに反映するか決めるとき
- [工場の成果の指標](factory-metrics.md)：PR に人の指摘を受けて push するとき、修正や revert の PR を書くとき、指標を集計して読むとき、モデルや Kiro の版を変えたとき
- [grilling の推奨の書き方](grilling-recommendations.md)：grilling のラウンドを書くとき、選択肢を比べて推奨を出すとき
