# 帳票設計ガイドラインの出典と適用範囲

## 位置づけ

帳票とは企業の経営活動に関わる書類で、帳簿と伝票の総称を指す。媒体は粘土板、紙、PDF などの電子データに変化したが、ある時点の取引状態を記録し契約者間の合意形成の証とする役割、監査や税務処理でビジネス活動の正当性を証明する正データとなる役割は変わっていない。
昨今の IT/DX 化でペーパーレスが進み紙の帳票は減っているが、電子帳簿保存法やインボイス対応などで帳票自体の重要性は変わらない。帳票設計は、枯れた技術ではなく、今なおビジネスとシステムを繋ぐコア技術である。

## 適用範囲と前提条件

- **対象スコープ**
  - 人間が利用する前提で、レイアウトが固定され視認性を担保した文書 (帳票) が対象
  - 対象とする媒体は、紙、PDF、レイアウトを組んだ Excel である
  - 二次利用を前提とした CSV やデータ出力の Excel、印刷用 CSS を適用した Web 画面、SVG 帳票は対象外
- **前提条件**
  - 人間を主たる利用者と定義する。AI エージェントだけで処理が完結し人間が直接確認しない場合は I/F として扱う
