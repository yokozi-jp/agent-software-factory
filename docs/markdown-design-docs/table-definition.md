# テーブル定義書 (ERD)

テーブル定義は A5:SQL Mk-2 を用い `erd.a5er` という名称で管理する。
保持期限と個人情報有無は `erd.a5er` で管理できないため、別で定義する。

## テーブル定義書

[A5:SQL Mk-2](https://a5m2.mmatsubara.com/)を用い、`erd.a5er` という名称で管理する。

以下の情報の管理は `erd.a5er` で行えないため、別で定義する。

- 保持期限
- 個人情報有無
